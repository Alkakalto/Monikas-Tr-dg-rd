# Monikas Trädgård Knivsta – webbplatsdemo

En responsiv, statisk presentationssajt framtagen som kunddemo för Monikas Trädgård Knivsta.

## Förhandsvisa lokalt

Servera mappen `dist` med valfri statisk webbserver, exempelvis:

```powershell
python -m http.server 4173 --directory dist
```

Öppna sedan `http://localhost:4173`.

## Publicering

Repositoryt innehåller ett GitHub Pages-arbetsflöde som publicerar innehållet i `dist` när ändringar skickas till `main`.

## Innan skarp publicering

- Bekräfta tjänsteutbud, telefonnummer och verksamhetsområde med kunden.
- Byt gärna demobilden mot kundens egna arbetsbilder efter godkännande.
- Omdömena i demon är varsamt förkortade/parafraserade från publikt tillgängliga Google-omdömen.
- Koppla en egen domän och komplettera med integritetstext om ett kontaktformulär eller analysverktyg läggs till.
